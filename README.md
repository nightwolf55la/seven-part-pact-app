# Seven-Part Pact

A persistent multiplayer web application for the tabletop RPG Seven-Part Pact.
Reliability, recoverability, and preservation of campaign state are higher
priorities than rapid feature delivery.

## Stack

- **Frontend:** React + Vite + TypeScript
- **Backend / authoritative state:** Convex
- **Hosting / deployment:** Vercel
- **Source control:** GitHub

## Local Quality Commands

```bash
npm ci          # install dependencies
npm test        # run automated tests (vitest)
npm run build   # type-check (tsc) + production build (vite)
npm run check   # test + build in one command
```

## Convex Generated Files

`convex/_generated/` is committed source generated by Convex tooling. Do not
manually edit it. After changes affecting Convex function/schema generated
types, run `npx convex codegen` locally, inspect the diff, and commit the
generated changes with the source change. CI's build gate verifies that source
compiles against the committed generated API.

## Campaign Health Verifier

The explicit campaign-health verifier is `verifyMigration:verifyMigration`.
The name is historical (from the v0.1 migration era) but it is the permanent
verifier. Conceptual invocation:

```
npx convex run verifyMigration:verifyMigration '{}' --deployment <deployment>
```

Healthy output has valid status, valid history control, valid checkpoint
verification, and no error arrays. Backup-import history is included.
